## Adding a post

1. Create a new folder such as `1-synthetic-consciousness/` with an `index.html`. The easiest starting point is to copy `0-the-start/index.html` and replace the title, date, canonical/og URLs, and article body.
2. Add a list item to `index.html` (day number, title, date, and link).
3. Add the post to the list above, with both the site URL and the X post URL.
4. Commit and push to `main`. Vercel will publish the new page at a path matching the folder name, for example `https://danbur-inkhaven.vercel.app/1-synthetic-consciousness/`.
